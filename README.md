# Майя Самчинская — светлый лендинг (maya-blue)

Третья версия лендинга: светлый редакционный дизайн по референсу психолога
в палитре из `colors/` — небесно-голубой #0593C6, белый #FCFFFF,
ярко-розовый #DB3996. Тонкие линейные иконки, рукописная заметка,
панель цитаты, фото в цвете с мягкими градиентными пятнами.

Другие версии: [igorshein/MAYA](https://github.com/igorshein/MAYA) (крем-бежевая),
[igorshein/MAYA-dark](https://github.com/igorshein/MAYA-dark) (тёмная).

## Структура
- `index.html` — одностраничный лендинг
- `assets/style.css`, `assets/script.js` — стили и логика (бургер, reveal, форма, модалка, cookie-баннер)
- `img/` — фото в цвете + фавикон
- `send.php` — обработчик формы: пишет заявку в `requests.json`, шлёт письмо при настроенной почте

## Перед запуском на PHP-хостинге
В `send.php` замените `MAIL_TO` и `MAIL_FROM` (`CHANGE-ME@example.com`).
Без этого заявки всё равно сохраняются в `requests.json` (не публиковать).

## Локальный запуск
```bash
python -m http.server 8080
```
Открыть http://localhost:8080.
